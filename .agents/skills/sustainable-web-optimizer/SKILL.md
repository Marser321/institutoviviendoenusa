# Optimizador Web Sostenible

Esta skill se enfoca en la **sostenibilidad digital**, un aspecto crucial en el desarrollo web moderno. Su objetivo es ayudar a crear sitios web más ligeros, rápidos y eficientes energéticamente, contribuyendo a reducir la huella de carbono de las plataformas digitales.

## Funcionalidades Clave

1.  **Auditoría de Impacto Ambiental**: Evalúa el consumo energético y las emisiones de CO2 de un sitio web, identificando áreas de mejora.
2.  **Optimización de Recursos**: Sugiere y aplica técnicas para reducir el peso de carga de imágenes, videos y otros activos, como el uso de formatos eficientes, lazy loading y carga condicional.
3.  **Gestión de Fuentes**: Recomienda el uso de fuentes del sistema o la optimización de fuentes personalizadas para minimizar el impacto en el rendimiento.
4.  **Diseño de Interfaz Eficiente**: Proporciona directrices para diseñar interfaces que requieran menos interacciones y clics, reduciendo el consumo de energía del usuario y del servidor.
5.  **Selección de Alojamiento Verde**: Ofrece información y recomendaciones sobre proveedores de hosting que utilizan energías renovables.

## Cómo Usar esta Skill

Para utilizar esta skill, el agente debe proporcionar:

-   **URL del Sitio Web**: La dirección del sitio a analizar.
-   **Objetivos de Optimización**: Metas específicas de rendimiento o reducción de impacto ambiental.
-   **Recursos Actuales**: Información sobre imágenes, videos, fuentes y otros activos utilizados.

La skill procesará esta información para:

-   Generar un informe detallado del impacto ambiental y el rendimiento actual.
-   Proponer un plan de optimización con acciones concretas.
-   Ofrecer scripts o configuraciones para implementar las mejoras sugeridas.

## Recursos Bundled

-   `scripts/`: Contendrá scripts para la optimización automática de imágenes, la configuración de lazy loading o la implementación de fuentes eficientes.
-   `references/`: Incluirá guías sobre métricas de sostenibilidad web, mejores prácticas de diseño ecológico y listas de proveedores de hosting verde.
-   `templates/`: Ofrecerá plantillas de informes de sostenibilidad y configuraciones de proyectos web optimizados.

Esta skill es esencial para desarrolladores y empresas que buscan construir soluciones web responsables con el medio ambiente y que, al mismo tiempo, ofrecen una experiencia de usuario superior gracias a su velocidad y eficiencia.
