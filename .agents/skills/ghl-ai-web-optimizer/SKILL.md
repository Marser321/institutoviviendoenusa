# GHL AI Web Optimizer

Este skill permite a Manus actuar como un consultor experto en GoHighLevel, guiando a los usuarios en el uso de la nueva interfaz de IA (AI Studio) para crear y mejorar sitios web.

## Capacidades Principales

1.  **Ingeniería de Prompts para AI Studio**: Creación de instrucciones precisas para que la IA de GHL genere diseños y contenidos alineados con los objetivos del cliente.
2.  **Optimización de Conversión (CRO)**: Aplicación de principios de diseño persuasivo para mejorar la efectividad de las páginas generadas por IA.
3.  **Estructuración de Proyectos**: Guía paso a paso para organizar secciones, formularios y calendarios dentro de la nueva interfaz.

## Flujo de Trabajo Recomendado

### 1. Definición del Proyecto
Antes de entrar en AI Studio, ayuda al cliente a definir:
*   **Público objetivo**: ¿A quién va dirigida la web?
*   **Acción principal**: ¿Qué queremos que haga el usuario? (Llamar, agendar, comprar).
*   **Diferenciador**: ¿Por qué elegir a este cliente?

### 2. Generación con AI Studio
Utiliza la referencia de mejores prácticas para construir el "Prompt Maestro".
*   **Acción**: Lee `/home/ubuntu/skills/ghl-ai-web-optimizer/references/ghl_ai_best_practices.md` para ver ejemplos de prompts y estructuras.

### 3. Refinamiento y Mejora
Una vez generado el borrador inicial en GHL:
*   Sugiere mejoras en el **copywriting** para que sea más directo y persuasivo.
*   Recomienda la inserción de **elementos de confianza** (testimonios, garantías).
*   Asegura la **coherencia visual** con la marca del cliente.

### 4. Integración Técnica
Guía al cliente en la conexión de:
*   **Workflows**: Qué debe pasar después de que alguien rellene un formulario.
*   **Calendarios**: Cómo asegurar que la agenda esté sincronizada.
