# Guía de Diseño Cinematográfico e Impacto Visual (2026)

Esta guía establece los estándares para transformar sitios web convencionales en experiencias visuales de alto impacto utilizando técnicas cinematográficas y pensamiento lateral.

## 1. El Concepto de "Héroe Cinematográfico"
Un sitio web debe sentirse como el inicio de una película. No solo es información, es atmósfera.
*   **Video de Fondo Optimizado:** Uso de videos de alta calidad (comprimidos) que muestren el producto en acción o transmitan una emoción específica.
*   **Tipografía de Cartelera:** Uso de fuentes *variable fonts* con escalas exageradas. Títulos que no solo se leen, sino que "se sienten".
*   **Efecto "Windshield Wipe":** Micro-interacciones que revelan contenido a medida que el usuario interactúa, similar a un barrido de cámara.

## 2. Pensamiento Lateral: La Metáfora Visual
En lugar de usar iconos genéricos, utiliza metáforas basadas en materiales reales:
*   **Seguridad/Confianza:** Texturas de piedra, mármol o concreto.
*   **Tecnología/Innovación:** Vidrio, metal líquido, efectos de *glassmorphism* (iOS Liquid Glass).
*   **Creatividad/Agilidad:** Formas líquidas, neones, elementos flotantes 3D.

## 3. Elementos de Impacto Visual (Tendencias 2026)
| Técnica | Aplicación en GHL | Impacto |
| :--- | :--- | :--- |
| **WebGL / 3D Inmersivo** | Integración de Spline o Rive | Gamificación y retención del usuario. |
| **Cyberbrutalism** | Layouts asimétricos, ruido digital | Diferenciación radical en mercados saturados. |
| **Micro-interacciones Emocionales** | Efectos de hover "satisfactorios" | Conexión emocional con la marca. |
| **Sonido Sutil** | Feedback auditivo en clics (opcional) | Experiencia multisensorial. |

## 4. Auditoría Creativa: Preguntas de Pensamiento Lateral
Para auditar un proyecto, hazte estas preguntas:
1.  Si este sitio fuera una película, ¿de qué género sería? ¿El diseño actual encaja con ese género?
2.  ¿Qué pasaría si eliminamos el 50% del texto y lo contamos solo con una imagen/video?
3.  ¿Cómo podemos romper la "cuadrícula" (grid) para que el usuario sienta que está explorando un espacio, no leyendo un documento?
4.  ¿Cuál es el "momento de asombro" (Aha! moment) visual de esta página?

## 5. Instrucciones para la IA de GHL (AI Studio)
Cuando uses AI Studio, pide específicamente:
*   "Genera un layout con **jerarquía visual volumétrica** y profundidad."
*   "Usa una paleta de colores **cyberbrutalista** con alto contraste."
*   "Crea una sección de héroe con **estética cinematográfica de pantalla ancha**."
